Query the Cloudflare Radar API to retrieve information about a domain's global ranking or an Autonomous System Number's (ASN) organization and location.

## API Reference

### `GET /radar`

Returns one fact from Cloudflare Radar: domain ranking or ASN details.

**Parameters**

Provide **one** of:

- **`domain`** `string` - Domain name (e.g., `cloudflare.com`)
- **`asn`** `string` - ASN number with or without `AS` prefix (e.g., `13335` or `AS13335`)

**Example request (domain)**

```bash
curl https://radar-one-question.example.workers.dev/radar?domain=cloudflare.com
```

**Example response**

```json
{
  "type": "domain",
  "target": "cloudflare.com",
  "fact": "Domain rank in global top domains",
  "ranking": 150
}
```

**Example request (ASN)**

```bash
curl https://radar-one-question.example.workers.dev/radar?asn=13335
```

**Example response**

```json
{
  "type": "asn",
  "target": "AS13335",
  "fact": "ASN owned by Cloudflare, Inc. (CLOUDFLARENET) in US"
}
```

**Error responses**

- `400` - Missing both `domain` and `asn`, or both provided
- `502` - Radar API error or unreachable

**Error codes**

- `MISSING_PARAMETER` - Neither domain nor asn provided
- `INVALID_PARAMETER` - Both domain and asn provided
- `RADAR_ERROR` - Cloudflare Radar API returned an error

## Use Cases

- Domain reputation and ranking lookups from the edge
- ASN ownership and geolocation queries
- Network research tools and dashboards
- Educational demos of Cloudflare Radar capabilities
- Threat intelligence and abuse investigation workflows

## Limitations

- Returns one fact per request (either domain ranking or ASN details)
- Domain ranking data reflects Cloudflare Radar's public dataset
- ASN details depend on Radar's entity database
- No persistent storage or caching
- Rate limits determined by Cloudflare Radar API
