## October 1, 2026

- **Homepage refresh** - Curated featured experiments with binding chips and Deploy buttons, a category overview instead of the full catalog, and experiment counts derived from the repo
- **Try it block** - Every experiment page now opens with an example request, a sample response, and a Deploy button
- **Experiment index** - The [Introduction](/docs#experiment-categories) page lists every experiment with links, grouped by category
- **12 new life-improving experiments**, including:
  - [MCP Tools Server](/experiments/mcp-tools-server) - remote MCP (Agents SDK) with DNS, headers, uptime, and hash tools
  - [Receipt Parser](/experiments/receipt-parser), [Article to Audio](/experiments/article-to-audio), [Natural Language Calendar](/experiments/natural-language-calendar)
  - [Accessibility Auditor](/experiments/accessibility-auditor), [Privacy Tracker Scanner](/experiments/privacy-tracker-scanner)
  - [Domain Expiry Reminder](/experiments/domain-expiry-reminder), [Static Form Backend](/experiments/static-form-backend)
  - [One-Time Secret](/experiments/one-time-secret), [Newsletter Digest](/experiments/newsletter-digest)
  - [Access JWT Validator](/experiments/access-jwt-validator), [Image Converter](/experiments/image-converter)

## September 30, 2026

- **Use in your project** - Experiment docs can include a pasteable core via `<UseInYourProject>` (source files + usage example) for small lib helpers
