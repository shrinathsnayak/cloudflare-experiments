A curated collection of experiments demonstrating what developers can build using **most Cloudflare products** - not Workers alone.

The goal of this repository is to showcase **real-world developer tools and utilities** built on the **Cloudflare platform**. Experiments typically deploy as Workers that wire products together (Workers AI, D1, R2, Durable Objects, Browser Rendering, Access, Email, and more), often without a traditional backend.

## What You'll Find Here

Each experiment is:

- **Product-focused** - Maps to one Cloudflare product or platform capability
- **Small and focused** - Single responsibility, easy to copy
- **Independently deployable** - Every experiment has its own deploy button
- **Easy to understand** - Clear code structure with TypeScript
- **Fast to run** - Designed to execute in under 60 seconds
- **Click-to-deploy** - One-click deployment (usually to Cloudflare Workers)

## Why This Project Exists

Most Cloudflare tutorials show very simple examples (Hello World, basic KV counters, simple fetch). This repository focuses instead on **real tools developers would actually want to use**.

Each experiment is production-ready and demonstrates a complete use case that you can deploy, customize, and learn from.
